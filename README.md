# 🍽️ Restaurants Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing restaurant data to uncover meaningful insights related to restaurant performance, customer behavior, delivery operations, ratings, pricing, and overall business performance.

The analysis was performed using **Power BI**, with data cleaning and transformation carried out using **Power Query** and analytical calculations created using **DAX**.

The final result is an interactive multi-page Power BI dashboard designed to help understand restaurant performance and customer trends.

---

## 🎯 Objectives

- Analyze overall restaurant performance
- Understand customer behavior and preferences
- Analyze restaurant ratings and reviews
- Identify pricing and cost patterns
- Evaluate delivery and operational performance
- Compare restaurants across different locations and categories
- Identify key business insights from the data
- Build an interactive and professional Power BI dashboard
